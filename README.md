# Datheon Python Internship

This repository contains the projects and tasks completed as part of my **Python Internship at Datheon**. The projects focus on practical applications of Python, Large Language Models (LLMs), prompt engineering, Retrieval-Augmented Generation (RAG), and AI agents.

## 📂 Internship Tasks

### Task 1: Structured LLM Prompt Pipeline & JSON Extractor

A Python-based pipeline that extracts structured information from unstructured text, such as invoices and resumes, using Google Gemini, Pydantic schema validation, and few-shot prompt engineering.

**Key concepts:**
- Large Language Models (LLMs)
- Prompt engineering and few-shot examples
- Structured JSON extraction
- Pydantic schema validation
- Gemini structured output

📁 **Folder:** [`Task 1`](./Task%201/)

### Task 2: Document Q&A Assistant (RAG + Vector Embeddings)

A Retrieval-Augmented Generation (RAG) system that answers questions based on PDF documents. It uses LangChain, Google Gemini embeddings, and ChromaDB to retrieve relevant information and generate context-grounded answers with source-page citations.

**Key concepts:**
- Retrieval-Augmented Generation (RAG)
- Document ingestion and text chunking
- Vector embeddings and semantic search
- ChromaDB vector database
- Source citations and grounded responses

📁 **Folder:** [`Task 2`](./Task%202/)

### Task 3: Multi-Tool Autonomous AI Agent

A LangChain-powered AI agent that selects and uses tools to answer user queries. The available tools include a Python calculator, a sandboxed local file reader, and DuckDuckGo web search.

**Key concepts:**
- AI agents and tool calling
- LangChain agent workflows
- Safe Python expression evaluation
- Local file reading
- Web search integration
- Error handling and automated testing

📁 **Folder:** [`Task 3`](./Task%203/)
